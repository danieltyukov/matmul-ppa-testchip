# Figures

Every figure here is generated by a committed script from a committed measurement.
None is hand-drawn or hand-edited, so `make images` reproduces all of them and a stale
figure is a bug rather than an inevitability.

| Figure | Generated by | From |
|---|---|---|
| `architecture.svg` | `tools/svg_architecture.py` | the geometry parameters in `rtl/pkg/gemm_pkg.sv` |
| `dataflow_output_stationary.svg` | `tools/svg_dataflow.py` | the same parameters |
| `memory_map.svg` | `tools/svg_memory_map.py` | the opcode and bit-field constants the protocol tests assert against the chip |
| `spi_frame_timing.svg` | `tools/svg_spi_timing.py` | `results/trace/spi_frame.json`, a real captured frame |
| `ppa_area.png` | `tools/plot_ppa.py` | `results/synth/generic/summary.json` |
| `ppa_area_sg13g2.png` | `tools/plot_ppa.py` | `results/synth/sg13g2/summary.json` |
| `ppa_depth.png` | `tools/plot_ppa.py` | `results/synth/generic/summary.json` |
| `ppa_cycles.png` | `tools/plot_ppa.py` | `results/perf/cycle_counts.json` |
| `ppa_pareto.png` | `tools/plot_ppa.py` | all three of the above |
| `activity_totals.png` | `tools/plot_activity.py` | `results/activity/gate_summary.json` |
| `activity_vs_signs.png` | `tools/plot_activity.py` | `results/activity/gate_summary.json` |
| `activity_modules.png` | `tools/plot_activity.py` | `results/activity/engines_neg*.json` |
| `floorplan_estimate.png` | `tools/plot_floorplan.py` | `results/synth/generic/summary.json` |

The SVGs are hand-authored markup emitted from Python rather than a drawing tool
export: the labels come from the same parameters as the RTL, so a change to `MAT_*` or
`TILE_*` moves the figure with it.

The plotting scripts refuse to draw when the data they need is missing, rather than
substituting a placeholder. If `make images` fails with a message about a missing
results file, run the step it names.

## floorplan_estimate.png is not a layout

It is a treemap of synthesised cell counts. Block sizes are proportional to area and
positions are arbitrary. No place and route has been run, because OpenROAD and the IHP
SG13G2 physical views are not installed in the environment this repository was
developed in. `tools/render_gds.py` renders a real GDS if you have one, and refuses
with an explanation if you do not.
